# ActiRune

ActiRune is a movement-powered fantasy RPG prototype built with Flutter.

The repository contains the Phase-1 product implementation, artwork-driven UI surfaces, movement verification, battle scaffolding, progression/economy contracts, and validation workflows.

See `ACTIRUNE_PRODUCT_AUTHORITY.md`, `CURRENT_PROGRESS.md`, and `PHASE1_CLOSEOUT.md` for project authority and status.
